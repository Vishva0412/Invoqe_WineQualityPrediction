
# Wine Quality Prediction Using Machine Learning

## 1. Project Overview
This project predicts whether red wine is of high quality or not using Machine Learning techniques.

The system uses different chemical properties of wine, such as acidity, alcohol, pH, and density, to predict wine quality.

## 2. Objectives
- Analyze the wine quality dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Train Machine Learning models.
- Evaluate model performance.
- Predict wine quality using user input.

## 3. Dataset
Dataset: Red Wine Quality Dataset

Source: UCI Machine Learning Repository

Dataset link:
https://archive.ics.uci.edu/dataset/186/wine+quality

## 4. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## 5. Machine Learning Models
- Logistic Regression
- Random Forest Classifier
